# fcc-caesar-chiper
Caesar Cipher

A beginner Python project that explores the Caesar cipher, a classical substitution cipher that shifts letters by a specified number of positions in the alphabet.

Features

- Shift letters using a numeric key.
- Transform text using alphabet positions.
- Experiment with basic encryption and decryption, if implemented.

Concepts Practiced

- Strings and character manipulation
- Loops and conditional statements
- Functions
- Arithmetic and the modulo operator
- Input validation

Requirements

- Python 3

How to Run

python caesar_cipher.py

Learning Goals

- Understand basic text transformation.
- Practice working with strings and character positions.
- Apply loops and arithmetic to solve a programming problem.

Security Note

The Caesar cipher is intended for educational purposes. It is not secure for protecting sensitive information.
